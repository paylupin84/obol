자주 묻는 질문

계정이 정지되지 않나요?

안전하다고 말씀드릴 수 없습니다. 위의 안내처럼 게임 파일·메모리를 건드리지 않고 키는 복사 한 번만 보내지만, 허용 여부는 확인되지 않았습니다. 판단은 본인 몫입니다.

'271초 대기'가 뜨는데요?

카카오 거래소 호출 한도가 IP별이라 연속 조회하면 걸립니다. Obol 은 한도 직전에 멈추고 남은 시간을 알려 줍니다. 조회 간격을 두세요.

시세가 이상해요 / 안 읽혀요

시세는 등록가라 장난 매물이 섞입니다(편차 경고가 뜹니다). 안 읽히면 관리자 권한 허용 여부와 전체 화면 독점 여부를 먼저 확인하고, 불편사항 보내기로 알려 주세요.

소스는 공개하나요? 어디에 접속하나요?

소스는 공개하지 않습니다. 접속처는 카카오 거래소, poe.ninja, poe2db, GitHub(업데이트 확인, 정밀 계산 묶음 내려받기)이며, '불편사항 보내기'를 누를 때만 그 글을 개발자에게 전송합니다. 채팅 단축키(F5 등)를 설정하면 그 키에서 /명령어 한 줄을 입력합니다.

화면을 녹화하나요?

"죽었을 때 직전 장면 보기"를 켜 두면, 게임 창이 맨 앞일 때만 화면을 작게 줄여 최근 12초를 메모리에만 기억합니다(디스크에 쓰지 않고 외부로 보내지 않음). 죽었을 때 그 장면을 작은 창으로 보여 주고, 사용자가 '저장'을 누를 때만 파일로 남깁니다. 게임 파일·메모리는 읽지 않으며 설정 탭에서 끌 수 있습니다. 죽은 뒤 '원인 추정'은 ① 게임이 스스로 쓰는 로그 파일의 사망 직전 60초 ② 화면 왼쪽 아래 생명력·보호막 숫자 부분을 윈도 내장 글자 읽기로 읽은 값을 봅니다. 게임에 기록되지 않는 '진짜 원인'이 아니라 추정입니다.

'정밀 계산'을 쓰려면 PoB 를 깔아야 하나요?

아니요. Path of Building(PoE2)의 계산 모듈(MIT 라이선스)만 추린 약 5MB 묶음을 처음 한 번 GitHub 에서 내려받아 Obol 이 직접 돌립니다. poe.ninja 캐릭터 링크로 불러온 내 빌드 기준이고 poe.ninja 데이터는 실시간이 아니라서 갱신 시각을 같이 보여 줍니다. 계산 못 하는 줄은 '계산 못 함'으로 두며, 실전 DPS 와 다를 수 있습니다.

PC 상태·메모리 정리는 안전한가요?

수치는 읽기만 합니다(관리자 권한 필요 없음). '메모리 정리'는 내가 체크한 프로그램만, 무엇이 닫히는지 보여 주는 확인 창을 거친 뒤에 닫습니다. Windows 필수 프로세스와 Obol 자신은 목록에 나오지 않고, 편집기·Claude 같은 주의 표시가 붙은 것은 경고에 동의해야만 닫힙니다. 저장하지 않은 작업은 사라질 수 있으니 확인 창을 읽어 주세요.

돈을 받나요?

무료이고 기능 제한이 없습니다. 후원은 도구 안의 ☕ 따뜻한 커피 한 잔에서 자유롭게 하실 수 있습니다.

FAQ

Could my account be banned?

We cannot say it is safe. As described above, Obol does not touch game files or memory and sends only a single copy keystroke, but whether it is allowed has not been confirmed. The decision is yours.

It shows a "wait 271 seconds" message?

The Kakao trade site rate-limits per IP, so repeated lookups hit the limit. Obol stops just before the limit and tells you how long to wait. Leave a gap between lookups.

Prices look wrong / the item is not read

Prices are asking prices, so troll listings get mixed in (a spread warning appears). If an item is not read, first check that you allowed administrator permission and that the game is not in exclusive fullscreen, then tell us via "Send feedback".

Is the source code public? What does it connect to?

The source is not public. It connects to the Kakao trade site, poe.ninja, poe2db and GitHub (update check and the precise-calculation bundle), and sends text to the developer only when you press "Send feedback". If you set chat hotkeys (e.g. F5), that key types a single /command line.

Does it record my screen?

If you turn on "replay before death", it keeps the last 12 seconds in memory only, scaled down and only while the game window is in front (nothing is written to disk or sent anywhere). When you die it shows that moment in a small window, and saves a file only if you press "Save". It does not read game files or memory, and you can turn it off in Settings. The after-death "cause estimate" looks at ① the 60 seconds before death in the log file the game writes itself and ② the life/shield numbers at the lower left of the screen read with Windows' built-in text recognition. It is an estimate, not the real cause, which the game does not record.

Do I need PoB installed for "precise calculation"?

No. Obol downloads a ~5 MB bundle containing only the calculation modules of Path of Building (PoE2) (MIT licence) from GitHub once and runs it itself. It works from your build loaded through a poe.ninja character link; poe.ninja data is not real-time, so the update time is shown. Lines it cannot calculate are marked "cannot calculate", and results can differ from real in-game DPS.

Are PC status and memory cleaning safe?

The figures are read-only (no administrator rights needed). "Memory cleaning" closes only the programs you tick, after a confirmation window shows what will be closed. Essential Windows processes and Obol itself never appear in the list, and anything flagged with a caution (editors, Claude, etc.) is closed only if you accept the warning. Unsaved work can be lost, so please read the confirmation.

Does it cost money?

It is free with no feature limits. If you wish, you can support it with ☕ "a warm cup of coffee" inside the tool.

  • ゲームが管理者権限で動くため、Obol も管理者権限の確認画面を出します。「はい」を押してください。
  • Windows が「不明な発行元」という警告を出すことがあります。署名のない個人制作のプログラムだからです。信頼できない場合は実行しないでください。信頼する場合は詳細情報 → 実行。上のハッシュと同じかどうかは Get-FileHash Obol.exe でも確認できます。
  • 保管庫・販売状況を使うには、設定タブで自分のアカウント名(例: 名前#1234)を一度入力してください。
  • POE2 を起動すると Obol が自動で起動します(設定で切れます)。ウィンドウモードまたはボーダーレスウィンドウでお使いください(排他的フルスクリーンでは画面が表示されません)。

よくある質問

アカウントが停止されませんか?

安全とは言えません。上記のとおりゲームのファイルやメモリには触れず、キーもコピーを1回送るだけですが、許可されているかどうかは確認できていません。判断はご自身でお願いします。

「271秒待機」と表示されます

カカオのトレードサイトの呼び出し上限は IP ごとなので、続けて検索すると引っかかります。Obol は上限の直前で止まり、残り時間を表示します。検索の間隔を空けてください。

相場がおかしい / 読み取れない

相場は出品価格なので、いたずらの出品が混ざります(ばらつきの警告が出ます)。読み取れない場合は、まず管理者権限の許可と排他的フルスクリーンでないことを確認し、「フィードバック送信」でお知らせください。

ソースは公開していますか? どこに接続しますか?

ソースは公開していません。接続先はカカオのトレードサイト、poe.ninja、poe2db、GitHub(更新確認と精密計算パックのダウンロード)で、「フィードバック送信」を押したときだけその文章を開発者に送ります。チャットのショートカット(F5 など)を設定すると、そのキーで /コマンド を1行入力します。

画面を録画しますか?

「死亡直前の場面を見る」をオンにすると、ゲームウィンドウが最前面のときだけ画面を小さく縮小して直近12秒をメモリ上にだけ保持します(ディスクへの書き込みも外部への送信もありません)。死亡時にその場面を小さなウィンドウで表示し、「保存」を押したときだけファイルに残します。ゲームのファイルやメモリは読み取らず、設定タブで切れます。死亡後の「原因の推定」は、① ゲーム自身が書くログファイルの死亡直前60秒、② 画面左下の生命力・シールドの数値を Windows 標準の文字認識で読み取った値、を見ます。ゲームが記録しない「本当の原因」ではなく推定です。

「精密計算」を使うには PoB をインストールする必要がありますか?

いいえ。Path of Building(PoE2)の計算モジュール(MIT ライセンス)だけを抜き出した約5MBのパックを初回に一度 GitHub からダウンロードし、Obol が自分で実行します。poe.ninja のキャラクターリンクで読み込んだ自分のビルドが基準で、poe.ninja のデータはリアルタイムではないため更新時刻を併せて表示します。計算できない行は「計算不可」とし、実際の DPS とは異なる場合があります。

PC の状態・メモリ整理は安全ですか?

数値は読み取るだけです(管理者権限は不要)。「メモリ整理」は、チェックしたプログラムだけを、何が閉じられるかを示す確認画面を経てから閉じます。Windows の必須プロセスと Obol 自身は一覧に出ず、エディタや Claude など注意表示が付くものは警告に同意した場合だけ閉じます。保存していない作業は失われることがあるので、確認画面をよく読んでください。

お金はかかりますか?

無料で、機能制限もありません。ご支援は、ツール内の ☕「温かいコーヒー一杯」から自由にしていただけます。

常见问题

账号会被封停吗?

我们不能说它是安全的。如上所述,它不接触游戏文件和内存,只发送一次复制按键,但是否被允许尚未得到确认。请自行判断。

出现“等待 271 秒”是怎么回事?

Kakao 交易网站的调用上限按 IP 计算,连续查询就会触发。Obol 会在达到上限之前停下,并告诉您还需等待多久。请在查询之间留出间隔。

价格不对 / 读取不到物品

价格是挂牌价,所以会混入恶搞挂牌(会出现差异警告)。如果读取不到,请先确认已允许管理员权限且游戏不是独占全屏,然后通过“发送反馈”告诉我们。

源代码公开吗?会连接哪些地方?

源代码不公开。连接的地方有 Kakao 交易网站、poe.ninja、poe2db 和 GitHub(检查更新、下载精确计算包),只有在您点击“发送反馈”时才会把文字发送给开发者。如果设置了聊天快捷键(如 F5),该键会输入一行 /命令。

会录制屏幕吗?

开启“查看死亡前画面”后,仅在游戏窗口位于最前面时,把画面缩小并将最近 12 秒只保存在内存中(不写入磁盘,也不发送到外部)。死亡时会在小窗口中显示那一刻的画面,只有在您点击“保存”时才会保存为文件。它不读取游戏文件和内存,可在设置中关闭。死亡后的“原因推测”会查看 ① 游戏自己写入的日志文件中死亡前 60 秒的内容,② 用 Windows 内置文字识别读取的屏幕左下角生命/护盾数值。这只是推测,并非游戏没有记录的真正原因。

使用“精确计算”需要安装 PoB 吗?

不需要。Obol 只会在首次使用时从 GitHub 下载一个约 5MB、仅含 Path of Building(PoE2)计算模块(MIT 许可证)的包,并自行运行。它基于通过 poe.ninja 角色链接载入的您的构筑;poe.ninja 数据并非实时,所以会同时显示更新时间。无法计算的行会标注“无法计算”,结果可能与游戏内实际 DPS 不同。

电脑状态和内存清理安全吗?

数值仅为读取(无需管理员权限)。“内存清理”只会关闭您勾选的程序,并且会先弹出确认窗口显示将关闭什么。Windows 必需进程和 Obol 自身不会出现在列表中,带有注意标记的程序(编辑器、Claude 等)只有在您接受警告后才会关闭。未保存的工作可能丢失,请仔细阅读确认窗口。

收费吗?

免费,没有功能限制。如果您愿意,可以通过工具内的 ☕“一杯温暖的咖啡”自由赞助。
