# Obol (오볼)

Path of Exile 2 (카카오게임즈) 한글 전용 **시세 · 보관함 · 제작** 도구입니다.

## 다운로드

**[Releases](../../releases/latest)** 에서 `Obol.exe` 를 받아 실행하면 됩니다. 설치는 필요 없습니다(파이썬도 필요 없음).

## 할 수 있는 것

- **시세 조회** — 게임에서 아이템에 마우스를 올리고 `Alt+D`. 옵션 수치 ±10% 범위로 비슷한 매물을 찾아 보여 주고, 줄에 마우스를 올리면 그 매물의 옵션이 보입니다.
- **이름으로 시세 검색** `Alt+S`, 마지막 결과 다시 보기 `Alt+Q`
- **보관함 현황** `Alt+M` — 내 매물의 총 가치와 변동
- **판매 현황** `Alt+N` — 판매 기록 보기(홈페이지의 '판매 기록'을 내 PC에서 읽어 옴)
- **가상 제작** `Alt+C` — 접두·접미 모드를 가중치대로 뽑아 보는 시뮬레이터. 만든 아이템과 비슷한 매물 시세도 볼 수 있습니다.
- **필터 커스텀** `Alt+F` — 루트 필터에 강조·소리를 추가
- 스킨 4종 + 직접 만드는 스킨, **게임을 켜면 자동 실행**(설정에서 끌 수 있음)

## 처음 켤 때 알아 둘 것

- 게임이 관리자 권한으로 실행되기 때문에 Obol 도 **관리자 권한 허용 창**이 뜹니다. '예' 를 눌러 주세요.
- 서명되지 않은 프로그램이라 윈도가 "알 수 없는 게시자" 경고를 보여 줄 수 있습니다. '추가 정보 → 실행' 으로 열 수 있습니다.
- 보관함·판매 현황을 쓰려면 **설정 탭에서 내 계정 이름**(예: `이름#1234`)을 한 번 입력하세요.
- 판매 기록 읽기는 이 PC의 크롬으로 내 계정에 로그인해서 **내 기록만** 읽습니다. 아이디·비밀번호는 저장하지 않습니다.
- 이 도구는 게임 화면을 읽거나 조작하지 않고, 게임 메모리를 건드리지 않습니다. 시세는 카카오 거래소 공개 검색과 poe.ninja 를 사용합니다.
