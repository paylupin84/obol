Obol 다운로드 (Windows) exe 파일 하나 · 설치 필요 없음 · 항상 최신 버전이 받아집니다

할 수 있는 것

Alt+D게임에서 아이템에 마우스를 올리고 누르면 비슷한 매물 가격(시세) 조회. 줄에 마우스를 올리면 그 매물의 옵션이 보입니다.
Alt+B빌드 연구소 — 유명 빌드(PoB 코드, pobb.in, poe.ninja 링크)를 가져와 내 빌드와 견주고, 맞출 옵션을 고르고 시세·제작으로 이어 갑니다.
Alt+C가상 제작 시뮬레이터 — 접두·접미 모드를 가중치대로 뽑아 보고, 만든 아이템의 비슷한 매물 시세까지.
Alt+M / N보관함 현황(내 매물 총 가치), 판매 현황
Alt+T / W거래소 사이트에서 같은 검색 열기 / poe2db 에서 아이템 열기
F5게임 안에서 /은신처 (설정에서 바꿀 수 있음)
탭DPS 계산기, 필터 커스텀, 스킨 4종 + 내 스킨, 불편사항 보내기

처음 켤 때

  • 게임이 관리자 권한이라 관리자 권한 허용 창이 뜹니다. '예'를 눌러 주세요.
  • 윈도가 "알 수 없는 게시자" 경고를 보이면 추가 정보 → 실행을 누르세요(서명되지 않은 프로그램입니다).
  • 보관함·판매 현황을 쓰려면 설정 탭에서 내 계정 이름(예: 이름#1234)을 한 번 입력하세요.
  • POE2 를 켜면 Obol 이 자동으로 켜지게 설정되어 있습니다(설정에서 끌 수 있음).
